# PlayClaw - AI Assistant Manager

一款基于 Electron + Vue 3 构建的 OpenClaw 桌面管理工具，可视化管理 OpenClaw AI 助手。

## 📋 功能特性

### 核心功能

1. 系统指令修复：清理/批量修复 OpenClaw 任务配置文件的系统指令问题
2. 一键优化：调整心跳间隔、Token 配置、安全管控、并发数等提升运行性能
3. 一键部署：自动化安装/配置 OpenClaw 环境
4. 渠道配置：支持飞书/钉钉等聊天渠道配置
5. 多Agent团队：创建AI员工团队（设计公司/工程团队等场景模板）
6. Gateway 健康管理：监控/重启 OpenClaw Gateway 服务
